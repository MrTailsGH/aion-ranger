# Оружейная Стрелка

Личная страница персонажа AION 2 (Global): экипировка, скиллы, стигмы, арканы и статы
в сравнении с гайдами стрелка Allyria и Johnpal.

- Данные берутся из официальной оружейной `aion2.plaync.com`.
- GitHub Actions обновляет их каждые 4 часа (`.github/workflows/update.yml`).
- Обновить вручную: вкладка **Actions** → **Update character** → **Run workflow**.
- Сменить персонажа: поправить `config.json` (`region`: eu / naw / nae / as / la).

Сайт не связан с NCSOFT.
