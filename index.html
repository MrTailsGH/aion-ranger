Один раз: ключ доступа GitHub. Кнопка запускает обновление на GitHub от вашего имени, для этого нужен ключ. Он хранится только в этом браузере и не попадает на сайт и в репозиторий. На телефоне его нужно ввести отдельно.
  1. Откройте github.com → новый fine-grained token.
  2. Token name: aion-ranger, Expiration: на ваш выбор (например, 1 год).
  3. Repository access: Only select repositories → aion-ranger.
  4. Permissions → Repository permissions → Actions: Read and write. Больше ничего не включайте.
  5. Generate token, скопируйте и вставьте сюда.
